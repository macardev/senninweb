# SenninWeb — AGENTS.md

## Stack
- **React 18**, **Vite**, **TailwindCSS 3**, **PostCSS**
- JavaScript (no TypeScript)
- `@` path alias → `./src` (configured in `vite.config.js`)
- React Router v7 (react-router-dom)
- `framer-motion` for animations
- **EmailJS** for contact form, **pdfmake** for PDF generation
- Deployed on **Vercel** (`vercel.json` rewrites SPA routes: `/blog`, `/gebze` → `/index.html`)

## Commands
| Command | What it does |
|---|---|
| `npm run dev` | Generates favicon.ico, starts Vite dev server |
| `npm run build` | Generates favicon.ico → validates blog HTML flags → builds → runs `postbuild.mjs` (prerender, sitemap, md mirrors) |
| `npm run validate-blog` | Checks blog sections with HTML tags have `"isHtml": true` |
| `npm run build-guide` | Renders the lead-magnet PDF from `scripts/guide/*.html` |
| `npm run preview` | Serves the built `dist/` |
| `npm run generate-favicon` | Regenerate favicon.ico from SVG only |
| `npm run prospect-clients` | Google Places API → scrape Gebze businesses → prospects.json |
| `npm run send-outreach` | Google Workspace SMTP + OpenAI → send personalized cold email batch |

No lint, typecheck, or test commands exist.

## Architecture
- **Routes**: `/` (Home), `/blog`, `/blog/:slug`, `/sss`, `/hakkimizda`, `/kocaeli`, `/bilecik`, `/hizmet/{web-tasarim,seo-ve-buyume,dijital-pazarlama}`, `/rehber/yurt-disindan-hasta-cekme`
- **Entry**: `src/main.jsx` → `src/App.jsx`
- **Layout**: `src/components/layout/Layout.jsx` renders Navbar + `<Outlet/>` + Footer; custom cursor (lazy, desktop-only hover-capable devices)
- **Home page** (`src/pages/Home.jsx`): Hero (eager), BlogCTA (eager), rest lazy-loaded inside `<Suspense>`
- **Blog pages** (`Blog.jsx`, `BlogPost.jsx`): lazy-loaded in App.jsx
- Blog data lives in `public/data/blog-posts.json` (loaded by `src/data/blogPosts.js`) as section-based typed content blocks
- **IMPORTANT — `isHtml` flag:** `BlogPost.jsx` renders a section's text as HTML **only** when the section has `"isHtml": true`. Any section containing tags (`<strong>`, `<a>`, `<em>`, `<table>`…) without the flag shows the raw tags on the page. Always add `"isHtml": true` to such sections. `npm run build` runs `scripts/validate-blog-posts.mjs` first and fails if a section is missing it (`npm run validate-blog` to check manually).
- `public/data/blog-posts.json` uses **CRLF** line endings; preserve them when editing programmatically (otherwise the whole file shows as changed in git).
- Production: sitemap auto-generated by `postbuild.mjs` into both `public/sitemap.xml` (source) and `dist/sitemap.xml` (production)

## CSS
- `src/index.css`: custom styles in `@layer base` or `@layer utilities`
- **IMPORTANT — CSS cascade:** Rules inside `@layer utilities {}` can be overridden by other Tailwind utility classes in the same layer. Styles outside any `@layer` (unlayered) have the **highest** cascade priority.
- **Blogpost link styling:** `<a>` tags rendered via `dangerouslySetInnerHTML` MUST use unlayered CSS rules (outside `@layer utilities`) to guarantee they beat Tailwind's inheritance chain. If a link fix isn't applying, move the rule out of its layer block.

## Automation — Client Outreach Pipeline

**`scripts/prospect-clients.mjs`** — Weekly Gebze business scraping
- Google Places API → Text Search for 16 categories (restoran, avukat, kuaför, etc.)
- Extracts name, address, phone, website, Google rating
- Tries to find email from website (scrapes homepage + contact page)
- OpenAI generates personalization note per prospect
- Saves to `public/data/prospects.json`

**`scripts/send-outreach.mjs`** — Daily cold email sending
- Reads `prospects.json`, picks batch due for their next email
- OpenAI generates personalized Turkish email
- Sends via Google Workspace SMTP (nodemailer → smtp.gmail.com, `business@senninweb.com`)
- Tracks warmup (5→8→12→15→20/day), gaps between emails (3-5 days), replies, bounces
- State in `scripts/outreach-state.json`

## Lead capture & motion
- `src/utils/leads.js`: WhatsApp number, path-aware WhatsApp openers, `trackLead()` → GA4 `generate_lead`. A delegated click listener (init in `main.jsx`) tracks every `wa.me` / `mailto:` / `tel:` link sitewide; tag placements with `data-lead-placement` or a parent `data-lead-zone`.
- `LeadDock.jsx` (lazy, in Layout): desktop WhatsApp FAB + one-time nudge, mobile sticky bar (WhatsApp / Ara / Teklif). Hidden over hero and while `#contact` is visible.
- **ICP / positioning:** health clinics wanting international patients (hair transplant, dental, aesthetic/beauty, veterinary). Single offer: "Hasta Kazanım Paketi", monthly, custom website design included (never templates). **Do not publish a price range anywhere on the site** (owner decision: it scares visitors off); copy says "kliniğinize özel aylık teklif" after a free analysis, international SEO + target-country backlinks, WhatsApp lead flow.
- **Funnel:** primary CTAs → free guide `/rehber/yurt-disindan-hasta-cekme` (`src/pages/Rehber.jsx`, soft-gated via EmailJS) → PDF download → WhatsApp "kısa analiz". `GUIDE_PATH` / `GUIDE_PDF_URL` live in `src/utils/leads.js`.
- **Guide PDF:** source `scripts/guide/yurt-disindan-hasta-cekme.html` → `npm run build-guide` (headless Chrome `--print-to-pdf`) → `public/rehber/yurt-disindan-hasta-cekme-rehberi.pdf`. Each `.page` must fit A4 (297mm); re-run after editing.
- `LeadMagnet.jsx`: guide promo section on home (before Testimonials).
- Motion system lives in `src/index.css` ("Motion system" block): Premium personality, CSS scroll-driven animations (`h3d-*` hero stack, `.reveal-3d`, `.scroll-progress`). All respect `prefers-reduced-motion`; unsupported browsers get the static end state. Motion design skill: `~/.claude/skills/motion-design`.
- **Static-first rendering (performance):** `index.html` has `#hero-host` (static content, painted before JS) above `#root` (React).
  - Home: the hero HTML/CSS comes from `src/content/heroMarkup.js`, injected by a Vite plugin in `vite.config.js` (`order: 'pre'`). `<Hero />` *adopts* that DOM node instead of re-rendering it (keeps LCP at first paint) and portals the 3D scene into `[data-hero-3d]`. Edit hero copy in `heroMarkup.js` only.
  - Other routes: `postbuild.mjs` swaps the block between `<!--prerender:start-->…<!--prerender:end-->` (inside `#hero-host`) for the page's static body (blog posts: full article; services: from `src/data/services.js`). Keep those markers.
  - Every page must call `useReleaseStaticBody(ready)` (`src/hooks/`) once its own content is rendered; CSS hides `#root` while a static page body is visible, so the swap causes no layout shift. New pages: add the hook, a prerender entry and a sitemap entry.
  - Home sections below the fold mount via `LazySection` (IntersectionObserver); `scrollToIdWithRetry` fires `sw:mount-all` for anchors and re-aligns while lazy sections settle.
  - Initial render runs inside `React.startTransition` (main.jsx) to keep TBT low.
- **Adaptive motion:** `<html data-motion="full|lite|off">` set by an inline script in `index.html` (reduced motion, Save-Data/slow network, low RAM) and downgraded at runtime by an FPS probe (`src/utils/motionTier.js`). `index.css` gates heavy effects (blur glows, mesh overlay, backdrop-filter, floating/tilt) by tier; JS effects check `getMotionTier()`.
- **Service pages:** content + JSON-LD (Service without price, FAQPage) in `src/data/services.js`, rendered by `src/components/service/ServicePage.jsx`. `postbuild.mjs` also writes `public/docs/hizmet/*.md` from it. `/hizmet/eticaret-cozumleri` 301 → `/hizmet/web-tasarim` (outside ICP).
- Blog posts: `question` sections are emitted as FAQPage JSON-LD (BlogPost.jsx + postbuild).
- **SSS:** single source `src/data/faqs.json` → `src/pages/SSS.jsx` (CSS accordion, answers stay in DOM), FAQPage JSON-LD, postbuild static body and `public/docs/sss.md`. Answers are plain text (`\n` for line breaks), no HTML.
- Lighthouse (local): `npm run build && npx vite preview`, then test URLs **with trailing slash** (e.g. `/blog/slug/`); without it vite preview serves the SPA fallback, unlike Vercel.
